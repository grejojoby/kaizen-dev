# Security policy

Kaizen Dev currently distributes Markdown instructions and evaluation examples. It has no runtime service, installer, telemetry, or code that processes project files.

If you find a security issue in this repository, do not include secrets, customer data, or an exploitable payload in a public issue. Use GitHub's private vulnerability reporting for the repository if enabled, or contact the maintainer through the private contact method published with the repository. If no private method is available, ask for one without posting sensitive details.

For reports about agent behavior, include the skill version or commit, host and model versions, task setup, and a redacted example. Do not attach private source code or credentials unless the maintainer has provided a secure channel.
